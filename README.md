# 旅程規劃

自用的旅遊安排網站。純前端(HTML/CSS/JS),無需建置、無後端;資料存在瀏覽器 localStorage。

## 使用

直接用瀏覽器開啟 `index.html`,或在此資料夾執行 `python3 -m http.server` 後開 http://localhost:8000。
可放到 GitHub Pages 等靜態空間。

## 功能

- **每日行程**:時間軸、拖曳或 ↑↓ 排序、依時間排序、可跨天移動。
- **推薦行程**(設定頁):輸入成人/孩童/長輩人數、旅遊風格、交通類型、步調後,產生每日活動骨架
  (有孩童會加午休、有長輩避開吃力行程)。為規則式推薦,**不含具體店名**,請自行填入實際地點。
- **交通/餐飲/住宿諮詢**:每天可按需展開,內容隨成員與交通類型變化,並可寫自己的筆記。
- **用 Claude 搜尋推薦真實景點與餐廳**(設定頁):網站產生提示詞,你貼到能上網搜尋的 Claude,再把回覆(JSON)貼回匯入。
  網站本身不連網搜尋、不含任何 API 金鑰;匯入後可按行程頁的「補齊座標」用 OpenStreetMap 逐筆查座標。營業時間與價格請自行再確認。
- **地圖**:Leaflet + OpenStreetMap;可搜尋地點取得座標、在地圖上點選新增,依天數著色並畫路線。
- **匯入 Google / Apple 地圖**:
  - 每日路線連結(Google 地圖、Apple 地圖);地圖上點選標記會開啟 Google 地圖;
  - 下載 **KML**,可匯入 Google 我的地圖(Apple 地圖不支援匯入檔案,請用連結)。
- **預算與記帳**:總預算/分類預算、多幣別(匯率自行輸入)、每人平均、行程預估 vs 實際花費。
- **匯出 PDF**:匯出視窗 →「產生 PDF」→ 在列印視窗選「另存為 PDF」。可選是否含預算與全部建議。
- **備份**:匯出/匯入 JSON(單一或全部旅程)。清除瀏覽器資料會遺失紀錄,請定期備份。

## 備註

- 地點搜尋使用 OpenStreetMap Nominatim,地圖圖磚來自 OpenStreetMap,皆需網路,請遵守其使用政策(自用低頻率即可)。
- Google 路線連結最多帶 11 個定位點(起點 + 9 中繼點 + 終點),超過會提示。
- Leaflet 1.9.4 已放在 `vendor/leaflet/`(BSD-2 授權)。
